\# Data Cleaning



\## Original Dataset



Rows: 9,683



Columns: 21



\## Missing Values



No missing values were found.



\## Duplicate Records



No completely duplicated rows were found.



The Order\_ID column contains repeated values because one order can contain multiple products. Therefore, Order\_ID duplicates were not removed.



\## Data Type Changes



\- Order\_Date converted to Date

\- Ship\_Date converted to Date

\- Sales converted to Decimal

\- Quantity converted to Whole Number

\- Discount converted to Decimal

\- Profit converted to Decimal



\## Column Name Standardization



Column names were renamed for readability and consistency.
